# 手机安装步骤(只剩这一步了)

网址已经部署好,电脑上已全部完成。你只要在手机上操作。

---

## 你的网址

```
https://bed-god.github.io/ledger/
```

---

## 手机操作(约 1 分钟)

### 1. 打开浏览器

手机连 WiFi,打开 **OPPO 自带浏览器**(或任何浏览器)。

### 2. 输入网址

地址栏输入上面那个网址,打开。

会看到「自动记账本」的「记一笔」界面。

### 3. 等 5 秒

**别急着退出**,停留 5 秒,让它把离线缓存下载完。

### 4. 添加到桌面

在浏览器里找菜单:

- **底部中间** 有个「≡」或「⋯」图标 → 点开 → 找「**添加到桌面**」
- 或 **右下角** 三个点 → 点开 → 找「**添加到主屏幕**」

### 5. 确认

弹窗问名字,默认"记账本",点「**添加**」或「**确定**」。

---

## 完成

回到手机桌面,多了一个 **「记账本」** 图标。

点开 → **满屏显示、没有地址栏**,就像正常 App。
以后**断网也能用**。

---

## 试一下

1. 点底部「**记账**」
2. 分类选「**吃喝**」
3. 金额输 `10`
4. 来源输 `测试`
5. 点「**保存记录**」

再点底部「**明细**」,能看到这笔 → 全部正常。

最后到「明细」页点那笔右边的「**删除**」清掉测试数据,就能正式用了。

---

## 出问题怎么办

| 现象 | 解决 |
|---|---|
| 手机打开是空白 | 等 10 秒刷新一次 |
| 找不到「添加到桌面」 | 在浏览器设置里搜"主屏幕";实在没有就当普通网页用,记账功能一样正常 |
| 图标是默认图案 | 正常,用几次安卓会自己更新 |
| 提示不安全/打不开 | 确认网址是 `https://` 开头,别漏了 `s` |

---

## 重要提醒

- **账目存在你手机浏览器里**,不在 GitHub 上。GitHub 上只有程序代码。
- **清理浏览器数据 / 卸载浏览器会删掉所有账目。**
- 请定期到「数据」页点 **导出全部数据**,把 JSON 存微信/网盘备份。
- 换手机:旧手机导出 → JSON 传新手机 → 新手机「数据」页点 **导入**。

---

## 功能

- **支出三类**:吃喝、外出交通、其他平台消费
- **收入**:单独统计,月底看净结余
- **每笔记来源**:美团/地铁/淘宝…… 钱花哪了随时回溯
- **月底自动结算**:打开 App 自动把过完的月份算好存档
- **导出**:JSON 全量备份 / CSV 当月明细
