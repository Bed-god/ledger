# 手把手操作(每一步都写清楚了)

一共 **3 个阶段**,大约 10 分钟。
你需要的:一台能上网的电脑 + 你的 OPPO A58 手机。

> 为什么要这么麻烦?
> 手机想把网页变成"桌面图标 App",浏览器强制要求网址必须是 **https**(安全网址)。
> 电脑上直接双击 html 是 `file://`,不符合要求。所以必须先把文件放到一个免费的网站空间上。

---

# 阶段一:注册 GitHub(电脑上做,约 3 分钟)

## 1-1 打开注册页

电脑浏览器地址栏输入,回车:

```
https://github.com/signup
```

## 1-2 填三项

1. **Email**:填你的邮箱
2. **Password**:设个密码(至少 8 位,要有数字和小写字母)
3. **Username**:起个英文用户名,例如 `zhangxiaoming2026`
   - 只允许英文、数字、连字符
   - 如果提示已被占用,换一个

点绿色的 **Create account**。

## 1-3 通过人机验证

会出现一个拼图/旋转图片的小游戏,按提示做完。

## 1-4 输入邮箱验证码

GitHub 会往你邮箱发一封 6 位数字的邮件。
去邮箱找到 **Launch code / 验证码**,填进去。

> 如果让你选套餐,选 **Free(免费)**。
> 如果问一堆问卷(团队人数、用途),直接拉到最下面点 **Skip personalization** / 跳过。

注册完就自动登录了。

---

# 阶段二:建仓库并上传文件(电脑上做,约 3 分钟)

## 2-1 新建仓库

地址栏输入:

```
https://github.com/new
```

## 2-2 填仓库信息

1. **Repository name** 填:`ledger`
   - ⚠️ 只能填这个英文,别填中文,也别加空格
2. **Description** 空着不填,没关系
3. 往下看,选 **Public**(默认就是)
   - ⚠️ 必须 Public。Private 的免费账户无法开启 Pages
4. 下面 "Add a README file" 等**三个勾选框全部别勾**
5. 点最下面绿色按钮 **Create repository**

## 2-3 进入上传页面

建好后会跳到一个新页面,页面上有一行小字链接:

```
uploading an existing file
```

**点它**。

> 找不到的话,直接在地址栏输入:
> `https://github.com/<你的用户名>/ledger/upload/main`
> 把 `<你的用户名>` 换成你注册时起的那个。

## 2-4 选择文件

1. 打开电脑文件资源管理器,进到:
   ```
   D:\记账本
   ```
2. 里面有 **5 个文件**:
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - `icon.svg`
   - `icon-maskable.svg`
3. 按 **Ctrl + A** 全选这 5 个文件

## 2-5 拖进去上传

把选中的 5 个文件,用鼠标**拖到网页上那个虚线框里**
(框里写着 "Drag files here to add them to your repository")

拖进去后,网页下方会列出这 5 个文件名。

> 拖不进去?点框里的 **choose your files**,然后选中那 5 个文件,点打开。

## 2-6 提交

1. 把页面往下拉到最底部
2. 找到 **Commit changes** 输入框(里面可能写着 "Add files via upload")
3. 不用改,直接点绿色按钮 **Commit changes**

等 3 秒,文件就传好了。

---

# 阶段三:开启网页服务(电脑上做,约 2 分钟)

## 3-1 打开设置

在你这个 `ledger` 仓库页面,点上方一排标签里的:

```
Settings
```

(图标是个齿轮 ⚙️;如果没有,把浏览器窗口拉宽一点就能看到)

## 3-2 找到 Pages

在左侧菜单往下滚,找到:

```
Pages
```

点它。

## 3-3 设置来源

在 **Build and deployment** 下面的 **Source** 下拉框:

1. 选 **Deploy from a branch**
2. 出现两个新下拉框:
   - **Branch**:选 `main`
   - 右边的文件夹:选 `/ (root)`
3. 点右边的 **Save** 按钮

## 3-4 等 1~2 分钟,拿到网址

刷新这个页面,顶部会出现一个绿色框,里面有你的网址:

```
https://<你的用户名>.github.io/ledger/
```

**例如**你用户名是 `zhangxiaoming2026`,网址就是:

```
https://zhangxiaoming2026.github.io/ledger/
```

**把这个网址复制下来。**

## 3-5 先在电脑上试一下(重要)

把网址粘到电脑浏览器新标签页打开。

- ✅ 看到"记一笔"的界面 → 成功,继续下一步
- ❌ 显示 404 → 说明还没部署完,**等 2 分钟再刷新**
- ❌ 一直 404 → 回 3-3 检查是不是选了 `main` 和 `/ (root)`,然后重新 Save

---

# 阶段四:手机上装成 App(手机操作,约 2 分钟)

## 4-1 打开浏览器

手机连上 WiFi,打开 **OPPO 自带浏览器**(或你习惯的任何浏览器)。

## 4-2 输入网址

在地址栏输入**阶段三拿到的那个网址**,打开。

## 4-3 等 5 秒

看到"记一笔"界面后,**停留 5 秒别退出**,让它缓存完毕。

## 4-4 添加到桌面

在浏览器里找菜单,通常是以下两种位置之一:

- **底部中间**有个「≡」或「⋯」图标 → 点开 → 找 **「添加到桌面」**
- **右下角**三个点 → 点开 → 找 **「添加到主屏幕」**

## 4-5 确认

弹出小窗口问名字,默认"记账本",直接点 **「添加」/「确定」**。

## 4-6 大功告成

回到手机桌面,多了一个 **「记账本」** 图标。
点开 → **满屏显示、没有地址栏**,和别人装的 App 一模一样。
以后**断网也能用**。

---

# 阶段五:试一下

点桌面「记账本」图标:

1. 点底部 **「记账」**
2. 分类选 **吃喝**
3. 金额输入 `10`
4. 来源输入 `测试`
5. 点 **「保存记录」**

再点底部 **「明细」**,能看到刚才那笔 → 一切正常。

最后回到「明细」,点那条记录右边的 **删除**,把测试数据清掉,就可以正式记账了。

# 出问题了怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 电脑打开网址是 404 | 还没部署完 | 等 3 分钟再刷新 |
| 一直 404 | 分支选错 | 回阶段三 3-3,确认是 `main` + `/ (root)`,重新 Save |
| 手机打开是空白 | 第一次加载慢 | 等 10 秒刷新 |
| 找不到"添加到桌面" | 浏览器菜单版本不同 | 在浏览器设置里搜"主屏幕";实在找不到就当普通网页用,功能一样 |
| 图标显示成默认图案 | 正常现象 | 安卓缓存图标,用几次就正常了 |

# 重要提醒

- **数据存在手机浏览器里**,不在 GitHub 上,GitHub 上只有程序代码。
- **清理浏览器数据 / 卸载浏览器会删掉所有账目。**
- 请每隔一段时间,在「数据」页点 **导出全部数据**,把 JSON 文件发到微信/网盘存一份。
- 换手机:旧手机导出 → 把 JSON 传到新手机 → 新手机「数据」页点 **导入**。

---

# 功能一览

- **支出三类**:吃喝、外出交通、其他平台消费
- **收入**:单独统计,月底看净结余
- **每笔都记来源**:美团/地铁/淘宝…… 钱花哪了随时回溯
- **月底自动结算**:打开 App 时自动把过完的月份算好存档
  - 统计每个分类花多少、占比多少、各来源出现几次
  - 存档只读,不影响原始记录
- **导出**:JSON 全量备份 / CSV 当月明细
