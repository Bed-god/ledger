# 五种记账方式

打开 App,底部有 6 个页面:**记账 / 明细 / 月结 / 规划 / 导入 / 数据**

## 方式一:手动记一笔(最常用)

1. 点「记账」
2. 选类型:支出 / 收入
3. 选分类:吃喝 / 外出交通 / 其他平台消费(收入时自动只剩「收入」)
4. 填金额
5. 填来源(如 美团、地铁、淘宝)
6. 点「保存记录」

## 方式二:一键模板(每天重复的固定开销)

**先建模板:** 按方式一填好一笔(比如 早餐 10 元)→ 点「**＋ 把当前填写存为模板**」

**以后使用:** 到「记账」页顶部点一下模板卡片,直接记好当天一笔。

- 模板卡片右边「×」可以删除模板
- 适合:早餐、地铁、房租、工资 这类天天/月月一样的

## 方式三:复制上一条

点「**↻ 复制上一条**」→ 自动带入上次的金额、来源、分类,改个数字就能存。
适合:连续记几笔类似的支出。

## 方式四:导入微信账单(最省事)

### 先在微信里导出
1. 微信 →「**我**」→「**服务**」→「**钱包**」
2. 右上角「**账单**」→ 右上角「**常见问题**」
3. 点「**下载账单**」→ 选「**用于个人对账**」
4. 选时间范围(比如上个月)→ 下一步
5. 填你的**邮箱** → 下一步 → 输入支付密码
6. 去邮箱收信,会收到压缩包和一个**解压码**
7. 电脑上解压,得到 **.csv 文件**

### 再导入到记账本
1. 打开记账本 → 点「**导入**」
2. 点「选择账单文件」→ 选那个 **.csv**(⚠️ 不是 zip)
3. 看到**预览**:识别出的分类、金额、是否重复
4. 确认没问题 → 点「**确认导入**」

系统会自动:
- 按商户名分类(美团/饿了么→吃喝,滴滴/地铁→交通,淘宝/拼多多→平台消费,红包/退款→收入)
- 跳过重复记录(重复导同一个月不会记两遍)
- 跳过失败的、待付款的、已退款作废的订单

## 方式五:导入支付宝账单

支付宝要**用电脑**导出:
1. 电脑浏览器打开 https://www.alipay.com ,扫码登录
2. 右上角「**服务大厅**」→「**自助服务**」
3. 「交易服务」里点「**交易记录**」
4. 选时间范围 → 下载 **Excel 格式**
5. 解压得到 **.csv**
6. 传到手机,按方式四导入

> 支付宝账单是 GBK 编码,记账本会自动识别,不用手改。

# 月底自动结算

不用你管。每次打开 App 会自动:

- 找出所有**已经过完**的月份
- 算出:总收入、总支出、结余、每个分类花了多少、占比多少、各来源出现几次
- 存成只读档案,在「月结」页随时查

**补录也能自动更新**:如果 9 月已经结算了,后来你又导入 9 月账单,下次打开 App 会自动**重新结算** 9 月,保证数字准确。

# 月度对比图(月结页顶部)

打开「月结」页,最上面就是对比图,一眼看出钱在往哪走。

## 怎么看

每个月一组**双柱**:

- 🟢 绿柱 = 该月收入
- 🔴 **分段柱** = 该月支出,按分类分段(见下)
- 柱子越高金额越大,月份从左到右按时间排

## 支出柱按分类分段

支出柱不是一整块红色,而是按你定的三类**竖向切开**:

- 🩷 粉 = 吃喝
- 🟡 黄 = 外出交通
- 🟣 紫 = 其他平台消费

**手指点一下柱子**,会弹出这个月各分类花了多少。段的比例就是当月花销构成。

## 环比涨跌

每个月下方有 **▲ / ▼ 百分比**,是**支出比上个月涨/跌了多少**:

- 🔺 ▲ 红色 = 涨了(破财)
- 🔻 ▼ 绿色 = 跌了(省钱)
- 持平 = 两月一样

第一个月、或上个月没数据时不显示。

## 超支提醒

**当某月支出 > 收入**,那个月会自动标出来:

- 月份变成**橙色**
- 上面出现 **⚠️** 和一个红色小字「超X元」
- 底部汇总会写:超支几个月、是哪几个月、总共超支多少

如果整个区间每月都有结余,底部会显示「所选区间每月都有结余 👍」。

# 分类月度预算(月结页第二张卡片)

给每个分类设一个月度上限,图上会自动画一条**橙色虚线**作为预算线。

## 怎么设

1. 到「月结」页,找到「**分类月度预算**」卡片
2. 在「吃喝」「外出交通」「其他平台消费」后面的框里填金额(如 2000)
3. 点「**保存预算**」

- **留空 = 不限制**,这个分类不参与预算判断
- 填错或想全部重来,点「**清除预算**」

## 超预算怎么提醒

三处都会提示,不会漏:

1. **预算行右边**实时显示百分比:
   - 🟢 绿色 = 花得少(80% 以下)
   - 🟡 黄色 = 接近上限(80% ~ 100%)
   - 🔴 红色 = 已超支
2. **卡片顶部红框**:直接写「⛔ 吃喝 超预算 ¥600.00(已用 ¥2600.00 / 预算 ¥2000.00)」
3. **图上**:超预算的那个月标 **⛔**,对应分类的色段会描一圈橙边

## 预算线说明

- 虚线高度 = **所有分类预算之和**(总预算线)
- 图例里写着「预算线 ¥2500.00」,这个金额就是虚线所在的高度
- 图表纵轴会自动把预算算进去,保证虚线永远可见

> 预算存在本机浏览器里,跟着账目一起备份(见「数据」页导出)。

# 对比图:选范围与汇总

## 选时间范围

两种方式:

1. **快捷按钮**(推荐):点「近3月」「近6月」「近12月」「全部」,一键切换
2. **自己选**:上面的「从 / 到」两个框,各点一下选年月

> 默认显示**近 6 个月**。
> 月份多的时候图表可以**左右滑动**看(比如选「全部」超过 10 个月)。

## 底部汇总那行

显示所选区间的合计:

```
区间 2026-06 ~ 2026-09:收入 ¥32000.00 · 支出 ¥32100.00 · 结余 ¥-100.00
超支 2 个月 07、09 月支出大于收入,合计超支 ¥3300.00
月度预算 ¥2500.00,5 个月超预算(⛔):07、08、09
带 * 的月份为实时数据(尚未归档结算)
```

**带 \* 的月份**表示那个月还没结束(或还没归档结算),数字是按当前记录**实时算的**,不是最终数。


## 例子:一眼看趋势

假设你的图长这样:

| 月份 | 收入 | 支出 | 结果 |
|---|---|---|---|
| 26/05 | 9000 | 4200 | 结余 4800 |
| 26/06 | 9000 | 8800 | 结余 200 |
| **26/07** | 9000 | 12000 | **超支 3000** ⚠️ |
| 26/08 | 9000 | 5400 | 结余 3600 |
| **26/09** | 9000 | 9100 | **超支 100** ⚠️ |

一眼就能看出 7 月和 9 月花超了。

# 规划页:存钱与耐花天数

用**上个月**的实际花销,推算本月能存多少、能撑几天。数据自动取自账目,不用手填。

## 怎么看

打开「规划」页,上面先显示**参考月的基础数据**:

```
参考 2026-09(共 30 天):收入 ¥9000.00 · 支出 ¥4500.00 · 结余 ¥4500.00
→ 日均支出 ¥150.00 · 本月(2026-10)已花 ¥3200.00
```

参考月份可以用上面的框自己换(默认上月)。

## 三个结果

### 1. 本月还能存

```
参考月总收入 − 本月已花 = 本月还能存
¥9000.00 − ¥3200.00 = ¥5800.00
```

- 🟢 绿色 = 还能存钱
- 🔴 红色 = 本月已花超过参考月总收入,**存不下钱**

### 2. 这笔存款能撑多少天

```
本月还能存 ÷ 日均支出 = 天数
¥5800.00 ÷ ¥150.00 ≈ 39 天
```

颜色提示:**绿** = 够一个月以上,**黄** = 半个月左右,**红** = 不到半个月。

### 3. 输入的金额能撑多少天

在下面输入框填一个数(如 3000),或者点 **1000 / 3000 / 5000 / 10000** 快捷键:

```
输入金额 ÷ 日均支出 = 天数
¥3000.00 ÷ ¥150.00 = 20 天
```

最下面还有三行明细,把两套口径并列摆出来,方便核对。

## 口径说明

- **日均支出** = 参考月支出 ÷ 该月**真实天数**(2 月按 28/29 天算,不是固定 30)
- **月收入** = 参考月的**总收入**,不扣支出(你要的口径)
- **天数** = 金额 ÷ 日均支出,向上取整
- 参考月没有任何记录时,会提示换个月份

# 手机 App(APK)与自动记账

除了这个网址,还做了一个**真正的手机 App**(APK 安装包),双击图标即开,断网也能用。

## 有什么不同

- **不用开浏览器、不用输网址**,桌面点图标直接进
- **多了实时自动记账**:微信/支付宝付款后自动识别金额,弹窗确认即入库

App 里的功能与网页版完全一样(记账 / 明细 / 月结 / 规划 / 导入 / 数据)。

## 怎么装

APK 在:`D:\记账本APK\记账本-v1.0.apk`

传到手机点开安装即可(需允许「未知来源」安装)。详细步骤看
`D:\记账本APK\安装说明.md`。

## 自动记账怎么用

装好后打开 App →「导入」页最上面有「自动记账(实时)」卡片 →
按提示开启**通知读取**与**付款页面识别**两个权限 →
在微信/支付宝付款完成后,记账本会弹出「识别到一笔支出 ¥xx」,确认分类即可。

> **为什么需要权限**:微信没有开放个人账单 API(其接口都是商户接口)。
> 所有自动记账 App 都靠这两个系统权限实现,这是技术前提。
>
> 识别不完整也没关系 ——「导入账单」的 CSV 导入是官方数据,可兜底补齐,
> 两者按「日期+类型+分类+金额+来源」自动去重,不会记两遍。

## 隐私

自动记账只读取微信、支付宝这两个 App 的界面文字用于匹配金额:
不读聊天内容、不读键盘输入、不联网、不上传、没有服务器。
识别后一定弹窗等你确认,不会自动入账。随时可在系统设置里关闭。

# 备份(重要!)

账目存在**手机浏览器本地**,不在云端。

- **清理浏览器数据 / 卸载浏览器 → 账目全丢**
- 请定期到「数据」页点「**导出全部数据**」,把 JSON 文件存到微信文件传输助手或网盘
- 换手机:旧机导出 → JSON 传新机 → 新机「数据」页点「**导入**」

导出的备份里包含:全部记录、全部月结、全部模板、全部预算设置。

# 常见问题

| 现象 | 解决 |
|---|---|
| 手机打开空白 | 等 10 秒刷新 |
| 找不到「添加到桌面」 | 浏览器设置里搜"主屏幕";找不到就当普通网页用,功能一样 |
| 导入提示"没找到表头" | 确认是微信/支付宝**原始导出**的 CSV,别自己改格式 |
| 导入时选了 zip | 先解压,再选里面的 .csv |
| 重复导入了同一份账单 | 不会重复记账,自动跳过 |
| 数字对不上 | 到「月结」页点「生成结算」重新算一次 |
