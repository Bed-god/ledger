## 手机操作(约 1 分钟)

### 1. 打开浏览器
手机连 WiFi,打开 **OPPO 自带浏览器**(或任意浏览器)。

### 2. 输入网址
地址栏输入上面那个网址,打开。看到「记一笔」界面。

### 3. 等 5 秒
**别急着退出**,停 5 秒,让它下载完离线缓存。

### 4. 添加到桌面
浏览器菜单里找:
- **底部中间**「≡」或「⋯」→ 点开 → 「**添加到桌面**」
- 或 **右下角** 三个点 → 「**添加到主屏幕**」

### 5. 确认
弹窗默认名字"记账本",点「添加」。

---

## 完成

桌面出现 **「记账本」** 图标,点开满屏无地址栏,**断网也能用**。

# 五种记账方式

打开 App,底部有 5 个页面:**记账 / 明细 / 月结 / 导入 / 数据**

## 方式一:手动记一笔(最常用)

1. 点「记账」
2. 选类型:支出 / 收入
3. 选分类:吃喝 / 外出交通 / 其他平台消费(收入时自动只剩「收入」)
4. 填金额
5. 填来源(如 美团、地铁、淘宝)
6. 点「保存记录」

## 方式二:一键模板(每天重复的固定开销)

**先建模板:** 按方式一填好一笔(比如 早餐 10 元)→ 点「**＋ 把当前填写存为模板**」

**以后使用:** 到「记账」页顶部点一下模板卡片,直接记好当天一笔。

- 模板卡片右边「×」可以删除模板
- 适合:早餐、地铁、房租、工资 这类天天/月月一样的

## 方式三:复制上一条

点「**↻ 复制上一条**」→ 自动带入上次的金额、来源、分类,改个数字就能存。
适合:连续记几笔类似的支出。

## 方式四:导入微信账单(最省事)

### 先在微信里导出
1. 微信 →「**我**」→「**服务**」→「**钱包**」
2. 右上角「**账单**」→ 右上角「**常见问题**」
3. 点「**下载账单**」→ 选「**用于个人对账**」
4. 选时间范围(比如上个月)→ 下一步
5. 填你的**邮箱** → 下一步 → 输入支付密码
6. 去邮箱收信,会收到压缩包和一个**解压码**
7. 电脑上解压,得到 **.csv 文件**

### 再导入到记账本
1. 打开记账本 → 点「**导入**」
2. 点「选择账单文件」→ 选那个 **.csv**(⚠️ 不是 zip)
3. 看到**预览**:识别出的分类、金额、是否重复
4. 确认没问题 → 点「**确认导入**」

系统会自动:
- 按商户名分类(美团/饿了么→吃喝,滴滴/地铁→交通,淘宝/拼多多→平台消费,红包/退款→收入)
- 跳过重复记录(重复导同一个月不会记两遍)
- 跳过失败的、待付款的、已退款作废的订单

## 方式五:导入支付宝账单

支付宝要**用电脑**导出:
1. 电脑浏览器打开 https://www.alipay.com ,扫码登录
2. 右上角「**服务大厅**」→「**自助服务**」
3. 「交易服务」里点「**交易记录**」
4. 选时间范围 → 下载 **Excel 格式**
5. 解压得到 **.csv**
6. 传到手机,按方式四导入

> 支付宝账单是 GBK 编码,记账本会自动识别,不用手改。

# 月底自动结算

不用你管。每次打开 App 会自动:

- 找出所有**已经过完**的月份
- 算出:总收入、总支出、结余、每个分类花了多少、占比多少、各来源出现几次
- 存成只读档案,在「月结」页随时查

**补录也能自动更新**:如果 9 月已经结算了,后来你又导入 9 月账单,下次打开 App 会自动**重新结算** 9 月,保证数字准确。

# 备份(重要!)

账目存在**手机浏览器本地**,不在云端。

- **清理浏览器数据 / 卸载浏览器 → 账目全丢**
- 请定期到「数据」页点「**导出全部数据**」,把 JSON 文件存到微信文件传输助手或网盘
- 换手机:旧机导出 → JSON 传新机 → 新机「数据」页点「**导入**」

导出的备份里包含:全部记录、全部月结、全部模板。

# 常见问题

| 现象 | 解决 |
|---|---|
| 手机打开空白 | 等 10 秒刷新 |
| 找不到「添加到桌面」 | 浏览器设置里搜"主屏幕";找不到就当普通网页用,功能一样 |
| 导入提示"没找到表头" | 确认是微信/支付宝**原始导出**的 CSV,别自己改格式 |
| 导入时选了 zip | 先解压,再选里面的 .csv |
| 重复导入了同一份账单 | 不会重复记账,自动跳过 |
| 数字对不上 | 到「月结」页点「生成结算」重新算一次 |
